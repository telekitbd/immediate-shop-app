# Immediate Shop — WebView Android App

এটি একটি সম্পূর্ণ Android Studio প্রজেক্ট যা আপনার ওয়েবসাইট (`https://immediate.rf.gd/`) — অ্যাডমিন প্যানেল সহ — একটি অ্যাপের ভেতরে লোড করে দেখাবে।

## এই অ্যাপে যা যা আছে
- পুরো সাইট (হোম পেজ, প্রোডাক্ট পেজ, লগইন, **অ্যাডমিন প্যানেল** — সব) একই WebView-তে লোড হয়, যেহেতু আপনার সাইটের সব লিংক একই ডোমেইনের ভেতরে
- পুল-টু-রিফ্রেশ
- লোডিং প্রোগ্রেস বার
- ইন্টারনেট না থাকলে "অফলাইন" স্ক্রিন + রিট্রাই বাটন
- ছবি/ফাইল আপলোড সাপোর্ট (অ্যাডমিন প্যানেলে প্রোডাক্ট ছবি আপলোডের জন্য দরকার)
- PDF/ইনভয়েস ডাউনলোড লিংক ব্রাউজারে খোলে
- ব্যাক বাটনে ওয়েবপেজ হিস্টোরিতে ফেরত যায় (একদম প্রথম পেজ হলে অ্যাপ বন্ধ হয়)

## কেন আমি সরাসরি .apk ফাইল দিতে পারিনি
APK বানাতে ও সাইন করতে Android SDK + Gradle বিল্ড টুলস লাগে, যা আমার চ্যাট এনভায়রনমেন্টে ইনস্টল করা নেই এবং প্রয়োজনীয় সার্ভারেও (Google Maven) নেটওয়ার্ক অ্যাক্সেস নেই। তাই সোর্স কোড রেডি করে দিয়েছি — নিচের ধাপ অনুসরণ করলে ৫-১০ মিনিটেই নিজে APK বানিয়ে ফেলতে পারবেন।

## APK বানানোর ধাপ

1. **Android Studio** ইনস্টল করুন (ফ্রি): https://developer.android.com/studio
2. এই পুরো `WebViewApp` ফোল্ডারটি Android Studio দিয়ে **Open** করুন (File → Open)।
3. প্রথমবার Gradle sync হতে কিছুটা সময় লাগবে (ইন্টারনেট লাগবে)।
4. (ঐচ্ছিক) নিজের মতো পরিবর্তন করুন:
   - **অ্যাপের নাম** → `app/src/main/res/values/strings.xml` এ `app_name`
   - **ওয়েবসাইট লিংক** → একই ফাইলে `site_url`
   - **প্যাকেজ নাম** → `applicationId` (app/build.gradle) এবং `namespace`
   - **অ্যাপ আইকন** → Android Studio-তে right click on `res` → New → Image Asset দিয়ে নিজের লোগো বসাতে পারবেন (এখন একটা সাধারণ প্লেসহোল্ডার আইকন আছে)
5. মেনু থেকে **Build → Build Bundle(s) / APK(s) → Build APK(s)** ক্লিক করুন।
6. বিল্ড শেষ হলে নিচে ডান কোণায় "locate" লিংক আসবে — সেখান থেকে `app-debug.apk` পাবেন। এটাই আপনার টেস্ট APK, ফোনে ইনস্টল করে চালাতে পারবেন।
7. Play Store-এ দেওয়ার মতো সাইন করা (release) APK/AAB বানাতে চাইলে: **Build → Generate Signed Bundle / APK** ব্যবহার করুন (একটি সাইনিং কী বানাতে হবে, Android Studio নিজেই গাইড করবে)।

## শুধু ফোন দিয়ে APK বানানোর উপায় (কম্পিউটার ছাড়াই)

কম্পিউটার লাগবে না — GitHub Actions ব্যবহার করে ক্লাউডে বিল্ড হবে, আপনি ফোন দিয়েই পুরো কাজ করতে পারবেন। এই প্রজেক্টে ইতিমধ্যে `.github/workflows/build-apk.yml` ফাইলটা যোগ করে দেওয়া আছে, যেটা অটোমেটিক APK বিল্ড করবে।

### ধাপগুলো (ফোনের Chrome ব্রাউজার বা GitHub অ্যাপ দিয়ে):

1. **GitHub অ্যাকাউন্ট খুলুন** (না থাকলে): https://github.com/signup
2. ওপরে ডানদিকে **+** আইকনে চাপ দিয়ে **New repository** সিলেক্ট করুন। নাম দিন (যেমন `immediate-shop-app`), **Public** বা **Private** যেকোনোটা রাখুন, তারপর **Create repository**।
3. নতুন খালি রিপোতে **"uploading an existing file"** লিংকে চাপ দিন (অথবা Add file → Upload files)।
4. আমার দেওয়া ZIP ফাইলটা আগে ফোনে এক্সট্র্যাক্ট করুন (যেকোনো ফাইল ম্যানেজার/ZIP এক্সট্র্যাক্টর অ্যাপ দিয়ে — যেমন "ZArchiver" বা ফোনের বিল্ট-ইন ফাইল অ্যাপ)। এক্সট্র্যাক্ট করা `WebViewApp` ফোল্ডারের **ভেতরের সব ফাইল/ফোল্ডার** (build.gradle, app, .github, ইত্যাদি — ফোল্ডারের ভেতরে ঢুকে সবকিছু, WebViewApp ফোল্ডারটা নিজে না) আপলোড করুন।
   - মোবাইল ব্রাউজারে GitHub-এর ফোল্ডার-সহ আপলোড কখনো কখনো ঝামেলা করে। সহজ বিকল্প: **"GitHub"** অফিসিয়াল মোবাইল অ্যাপ (Play Store) ইনস্টল করুন — সেখানে ফাইল আপলোড আরও মসৃণ। অথবা **Termux + git** দিয়ে কমান্ড লাইনে পুশ করাও যায়, তবে সেটা একটু টেকনিক্যাল।
5. আপলোড হয়ে গেলে নিচে **Commit changes** চাপুন।
6. রিপোর ওপরে **Actions** ট্যাবে যান। কিছুক্ষণের মধ্যে "Build Debug APK" নামে একটা রান শুরু হবে (হলুদ 🟡 → সবুজ ✅, সাধারণত ২-৪ মিনিট লাগে)।
7. রান শেষ হলে সেই রানের পেজে নিচের দিকে **Artifacts** সেকশনে `app-debug-apk` নামে একটা জিপ পাবেন — ট্যাপ করে ডাউনলোড করুন।
8. ওই জিপের ভেতরে `app-debug.apk` থাকবে — এটাই আপনার ইনস্টলযোগ্য APK। ফোনে ইনস্টল করার আগে Settings → "Install unknown apps" পারমিশন দিতে হতে পারে।

> নোট: এভাবে যেটা তৈরি হবে সেটা **ডিবাগ APK** (টেস্ট করার জন্য যথেষ্ট, নিজে ইনস্টল করে চালাতে পারবেন)। Google Play Store-এ আপলোড করার মতো সাইন করা **রিলিজ** ভার্সন বানাতে হলে পরে কম্পিউটারে Android Studio দিয়ে "Generate Signed Bundle/APK" করতে হবে (ওপরের সেকশনে বলা আছে)।

## গুরুত্বপূর্ণ নোট
- আপনার সাইট `http://` (নন-সিকিউর) হলে অ্যাপে `usesCleartextTraffic="true"` ও mixed-content allow করা আছে যাতে লোড হতে সমস্যা না হয়। সাইট HTTPS-এ থাকলে সবচেয়ে ভালো ও নিরাপদ হবে।
- অ্যাডমিন প্যানেলের লগইন সেশন/কুকি স্বাভাবিকভাবেই WebView-তে সংরক্ষিত থাকবে, যেমন নরমাল ব্রাউজারে হয়।
- QR কোড স্ক্যান বা ছবি তোলার ফিচার সাইটে থাকলে, ক্যামেরা পারমিশন অ্যাপে already যোগ করা আছে।
